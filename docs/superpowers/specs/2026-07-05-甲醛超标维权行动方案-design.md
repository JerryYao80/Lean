# 驻场办公场所甲醛超标维权行动方案

**日期**：2026-07-05
**适用情境**：乙方驻场（项目外包）开发团队，在甲方场地办公一个月后，经 CMA 资质检测确认甲醛超标 1.5 倍，团队出现眼/咽/呼吸道症状但未就医，维权主战场为乙方（用人单位），甲方场地作为危害源由行政机关自行追溯。
**核心法律抓手**：《劳动法》第 54 条、《职业病防治法》第 35/39 条、《劳动合同法》第 38/48/87 条。

---

## 0. 关键认知：环境超标 ≠ 职业病成立

甲醛超标 1.5 倍能否认定职业病，**不只看浓度数字**，需同时满足浓度、暴露时长、健康损害三要件，且浓度门槛按不同标准差异巨大：

| 标准 | 用途 | 甲醛限值 |
|---|---|---|
| GBZ 2.1（工作场所有害因素职业接触限值） | 职业接触判定 | MAC 0.5 mg/m³ |
| GB/T 18883（室内空气质量标准） | 办公/居住环境卫生达标 | ≤0.10 mg/m³（1 小时均值） |

**办公场景的"超标 1.5 倍"通常指相对 GB/T 18883 的 0.15 mg/m³，远低于 GBZ 2.1 的 0.5 mg/m³ 职业接触限值，大概率诊断不上职业病。**

因此维权重心从"职业病+工伤"调整为 **"劳动保护权 + 行政投诉 + 第 38 条解除补偿"三支柱**。这三支柱不要求达到职业病诊断门槛，只需乙方未履行劳动保护义务即可成立。

---

## 1. 方案骨架

```
第一阶段 D0-D1   证据固化 + 医疗补证      ← 立刻做，不可逆
第二阶段 D2-D7   书面函告乙方 + 设整改期   ← 先礼后兵，固定权利主张
第三阶段 D8-D20  行政投诉双轨（卫健+人社） ← 升级施压
第四阶段 D21+    视乙方反应选终局：改善留任 / 38条解除拿N / 违法解除拿2N
```

四阶段围绕一个核心：**无论结果如何，每一步都在积累"乙方未履行劳动保护义务"的证据**，最终筹码要么换改善，要么换补偿。

---

## 2. 第一阶段：证据固化 + 医疗补证（D0-D1，立即执行）

整条方案的命脉。后面所有动作的有效性都建立在证据是否扎实上。

### 2.1 CMA 报告核验
- 原件复印 3 份，扫描存档（云端+本地）
- 核对报告引用的是哪个标准（GB/T 18883 还是 GBZ 2.1）—— 决定浓度门槛定位
- 若报告只给甲方/乙方，团队没拿到原件，**立即向检测机构书面申请复印件**（作为受影响劳动者有权获取）

### 2.2 现场二次取证（防止甲方/乙方突击治理后销毁证据）
- 全员手机拍摄办公区全景、通风设备状态、新家具/装修痕迹
- 拍照 CMA 报告原件 + 现场日期同框（证明报告对应的就是这个场所）
- 录视频说明"X 月 X 日驻场办公区，CMA 报告显示甲醛超标 1.5 倍"
- 用便携检测仪在同点位复测一次，全程录像（佐证超标持续，非一次性）

### 2.3 医疗补证（关键短板补齐）
- 有症状的同事**今天就就医**，挂三甲医院呼吸科/耳鼻喉科/职业医学科
- 主诉模板："驻场办公场所甲醛超标（附 CMA 报告），出现眼刺痛/咽痛/咳嗽/头晕 X 周"
- 要求病历写明：① 症状 ② 与甲醛暴露的关联性判断 ③ 客观检查（肺功能/眼结膜/血常规）
- 保留病历、检查报告、发票、挂号单原件
- **未就医的同事也去查一次**，留基线数据（未来若出现迟发症状有对照）

### 2.4 劳动关系与场所证据
- 劳动合同、工资流水、社保记录（证明乙方是用工主体）
- 驻场打卡记录、工牌、甲方下发的进场通知（证明在甲方场地办公是乙方安排的）
- 微信群聊天记录截图（含乙方安排驻场、知情甲醛超标的对话）

### 2.5 团队内部组织
- 推选 1-2 名代表（避免分散被各个击破）
- 建私密群沟通，重要决定留文字
- 集体行动，签字委托代表处理维权事宜

## 3. 第二阶段：书面函告乙方 + 设整改期（D2-D7，先礼后兵）

核心目的不是真的指望乙方乖乖整改，而是**固定"已向用人单位主张权利"的证据**——这是后续行政投诉、劳动监察、第 38 条解除的法定前置要件。没这一步，乙方可以说"没人跟我反映过，我不知道"。

### 3.1 函告载体（决定证据效力）

| 渠道 | 证据效力 | 用法 |
|---|---|---|
| **EMS 邮寄** | ⭐⭐⭐ 最强 | 寄到乙方注册地法定代表人收，详情单写明"关于工作场所甲醛超标的劳动保护主张函" |
| **公司邮箱** | ⭐⭐⭐ 强 | 抄送 HR、项目经理、法定代表人邮箱，邮件标题同上 |
| **微信/钉钉** | ⭐⭐ 辅助 | 发给直属上级 + HR，截图保存（含未读/已读、发送时间） |

三渠道并行发送——任一渠道送达即生效，多渠道留痕防乙方以"没收到"狡辩。

### 3.2 主张函内容结构

> **标题**：关于工作场所甲醛超标要求履行劳动保护义务的函
>
> **第一段·事实陈述**
> 我们系乙方派驻甲方场地的驻场员工（附劳动合同、驻场通知）。X 年 X 月 X 日，经 CMA 资质检测，工作场所甲醛超标 1.5 倍（附 CMA 报告复印件）。自驻场以来，部分员工出现眼刺痛、咽痛、咳嗽、头晕等症状（附就医病历）。
>
> **第二段·法律依据**
> 依据《劳动法》第 54 条、《职业病防治法》第 39 条、《劳动合同法》第 38 条，乙方作为用人单位负有提供符合国家职业卫生标准工作场所、组织职业健康检查、告知工作场所危害因素的法定义务。
>
> **第三段·具体诉求（四项）**
> 1. 立即改善工作场所空气质量至 GB/T 18883 合格标准，或提供临时安全办公场所
> 2. 安排全体驻场员工职业健康检查（上岗前+在岗期间），费用由乙方承担
> 3. 承担已产生的相关医疗检查费用（附票据）
> 4. 改善期间工资照发，不得以此为由调岗降薪
>
> **第四段·整改期**
> 请于收到本函之日起 **7 日内**书面回复整改方案。逾期未回复或未整改，我们将依法向卫生健康监督所、人社局劳动监察大队投诉，并保留依据《劳动合同法》第 38 条单方解除劳动合同并主张经济补偿的权利。
>
> **落款**：全体驻场员工签字 + 日期 + 联系方式

### 3.3 关键动作细节
- **团队全员签字**（哪怕只签代表 + 其他人附《授权委托书》）——证明是集体主张，非个别人闹事
- **附 CMA 报告复印件 + 病历复印件**（让乙方无法说"未收到证据"）
- **EMS 单据保留**：详情单 + 邮寄底联 + 网站查询送达记录打印
- **发函后第三天**若乙方未回复，微信再催一次"X 月 X 日函是否收到，请回复"，留"已催办"证据

### 3.4 乙方可能反应及应对

| 乙方反应 | 应对 |
|---|---|
| 答应整改并落实 | 验收改善效果（复测甲醛），仍要求职业健康检查，方案到此结束 |
| 答应整改但拖延 | 进入第三节行政投诉，外部压力逼落地 |
| 推诿"甲方场地我们管不了" | 回函指出：用人单位义务不因场地是第三方而转移，法律依据不变，仍由乙方担责 |
| 报复性调岗/降薪/解除合同 | **不要主动提离职**。立即固定证据（书面调岗通知、降薪流水、解除通知），这是违法解除 2N 赔偿的标的 |
| 不回复 | 7 天期满直接进入第三节 |

### 3.5 避雷清单
- ⚠️ **不要口头沟通**：所有主张必须书面，口头承诺改了不算数
- ⚠️ **不要只发给直属上级**：上级没决策权，要直达 HR + 法定代表人
- ⚠️ **不要在函里威胁甲方**：主战场是乙方，提甲方会让乙方有借口联合甲方施压
- ⚠️ **不要主动提离职**：第 38 条解除是"以乙方过错为由"的单方解除，要等乙方拒不整改才用，提前用反成"主动离职无补偿"

## 4. 第三阶段：行政投诉双轨（D8-D20，外部施压）

函告只是"告诉乙方你有义务"，行政投诉是"让国家机关告诉乙方你没履行义务"。两轨并行、各有侧重，配合使用撬动效果最大。

### 4.1 轨道一：卫生健康监督所（管"场所 + 健康检查"）

**受理机关**：工作场所所在地（甲方场地所在区县）的**卫生健康委员会综合监督所**
**投诉渠道**：12345 政务热线转办 / 卫健委官网投诉入口 / 现场提交书面投诉
**法律抓手**：《职业病防治法》第 35 条（用人单位未组织职业健康检查）、第 39 条（未提供符合标准的工作场所）

**投诉材料**（现场递交 + 留受理回执）：
1. 书面投诉信（陈述事实 + 诉求 + 法律依据）
2. CMA 报告复印件
3. 乙方拒绝整改或拖延的证据（函告送达证明 + 7 日未回复/回复不力的证明）
4. 劳动合同 + 驻场证明（证明你们是该场所的劳动者）
5. 团队代表授权委托书 + 联系方式

**投诉核心诉求**（请卫健所做三件事）：
1. **现场监督检测**：派员到甲方场地对甲醛进行监督性复测（官方复检，证据效力强于 CMA 报告）
2. **责令限期改正**：责令乙方（及场所提供方甲方）整改至 GB/T 18883 合格
3. **查处未组织职业健康检查违法行为**：依据《职业病防治法》第 35 条，乙方应组织上岗前+在岗期间职业健康检查，未组织属违法行为，可处罚款

**预期效果与节奏**：
- 卫健所受理后通常 **7-15 个工作日**安排现场监督
- 现场复测若确认超标，会下达《卫生监督意见书》责令整改
- 对乙方未履行职业健康检查义务可立案处罚（警告+罚款，对企业有实际威慑）
- ⚠️ 风险：部分地区卫健所对"办公室甲醛"案件不如工业企业积极，可能建议走劳动监察——这正是为什么要双轨并行

### 4.2 轨道二：人社局劳动监察大队（管"劳动保护义务 + 工资待遇"）

**受理机关**：乙方注册地或工作场所所在地的**人社局劳动保障监察大队**
**投诉渠道**：12333 劳动保障热线 / 全国劳动保障监察线上平台 / 现场投诉窗口

**投诉核心诉求**（与卫健所错位，聚焦劳动关系）：
1. **未提供劳动保护**：依据《劳动法》第 54 条，乙方未提供符合国家职业卫生标准的工作场所
2. **未组织职业健康检查**：依据《职业病防治法》第 35 条（与卫健所诉求重叠是故意的——双部门都施压）
3. **改善期间不得克扣工资/调岗降薪**：预防乙方以"不上班"为由扣薪
4. **若已发生调岗降薪/威胁解除**：主张违法，要求恢复原岗原薪

**劳动监察的优势**：
- 处理周期较短（立案后 60 个工作日内出结果）
- 人社部门对"办公场所劳动保护"比卫健所更熟悉（劳动争议老主战场）
- 监察结果可作为后续劳动仲裁的官方认定证据
- 若乙方拒不整改，人社局可列入劳动保障守法诚信"黑名单"，对企业招投标有实质影响

### 4.3 双轨协同关键策略

1. **同步提交，不要等一轨出结果再走另一轨**——两轨同步启动，乙方同时收到两个部门的询问/调查通知，压力叠加
2. **投诉主体要精准**：
   - 卫健所投诉对象：**乙方（用人单位）** + 说明甲方是场所提供方（让行政机关自行追溯甲方，不"惹"甲方）
   - 人社局投诉对象：**乙方**（劳动关系主体，与甲方无关）
3. **每次与行政机关接触都要留痕**：
   - 受理回执、调查通知书、监督意见书——全部复印存档
   - 与办案人员沟通尽量用书面/邮件，电话沟通后补一封"确认刚才电话沟通内容"的邮件
   - 这些文书是后续劳动仲裁/诉讼的核心证据
4. **复测机会要抓住**：
   - 卫健所现场监督检测时，团队代表务必到场，全程录像
   - 拿到官方监督检测报告后，**这就是比 CMA 报告更强的法定证据**——如果乙方后续报复解除合同，这份报告支持拿 2N

### 4.4 第三方渠道：工会

如果乙方有工会，向工会反映；如果无工会，向所在地总工会职工服务中心求助。工会虽无执法权，但有法定监督权，能协调劳动监察，且**工会介入后乙方报复劳动者构成违法情节加重**（《工会法》第 21 条）。这条线零成本，建议同步发起。

### 4.5 乙方常见反应与应对

| 乙方反应 | 应对 |
|---|---|
| 主动联系协商解决 | 可以谈，但**不撤行政投诉**——撤了就失去筹码。谈妥后再撤 |
| 找甲方联合施压要求撤诉 | 拒绝。甲方不是投诉对象，无权要求撤诉；乙方也无权代表你们撤诉 |
| 拖延等监察出结果 | 让监察流程走完，结果本身就是证据 |
| 期间报复调岗降薪/解除 | 立即固定证据，进入第四节终局——这反而送你 2N 筹码 |
| 整改了但拒绝职业健康检查 | 继续推进投诉，健康检查是法定义务不能省 |

## 5. 第四阶段：终局选择（D21+，视乙方反应定终局）

终局不是预设的，而是**由乙方反应决定走哪条终局**。三条终局路径相互独立，触发条件清晰。

### 5.1 终局一：改善留任（最优解）

**触发条件**：乙方在行政压力下落实整改，甲醛复测合格，并安排了职业健康检查。

**验收清单**（不要乙方说"改好了"就接受，要逐项验收）：

| 验收项 | 验收标准 | 验收方式 |
|---|---|---|
| 场所空气质量 | 甲醛 ≤0.10 mg/m³（GB/T 18883） | **独立复测**，不能只信乙方数据 |
| 职业健康检查 | 全员完成，含上岗前+在岗期间项目 | 查体检报告原件，留复印件 |
| 医疗费用 | 已产生的就医费用报销 | 凭票据报销到账 |
| 工资待遇 | 整改期间工资照发，未调岗降薪 | 查工资流水 |
| 后续保障 | 建立定期检测机制（如每季度一次） | 要求书面承诺 |

**关键动作**：
- 改善后**仍保留所有证据**（CMA 报告、监督意见书、病历）——未来若出现迟发健康损害，仍有追溯依据
- **不主动撤行政投诉**，除非乙方书面承诺全部落实并实际履行——撤早了筹码就没了
- 留任后注意观察是否有"穿小鞋"迹象（绩效打低、任务边缘化），这些都可成为后续主张的证据

### 5.2 终局二：第 38 条解除 + 经济补偿 N（主动止损）

**触发条件**：乙方经函告 + 行政投诉后**仍未整改**（甲醛仍超标 / 未安排健康检查 / 推诿拖延），决心离开。

**法律依据**：《劳动合同法》第 38 条第 1 款第 1 项——用人单位未按照劳动合同约定提供劳动保护或者劳动条件，劳动者可以**立即解除劳动合同**，且**无需提前 30 天通知**，并主张经济补偿（N）。

**N 的计算**：每满 1 年支付 1 个月工资（6 个月以上不满 1 年按 1 年算，不满 6 个月按半个月算），月工资按解除前 12 个月平均工资算。

**操作步骤**（顺序不能错）：
1. **确认前置证据齐全**：函告送达证明 + 7 日未整改证明 + 行政投诉受理/处理文书 + CMA 报告 + 病历
2. **发《被迫解除劳动合同通知书》**给乙方（EMS + 邮箱 + 微信三轨）
   - 标题明确："因用人单位未提供劳动保护被迫解除劳动合同通知书"
   - 正文写明：解除依据（第 38 条）、解除原因（甲醛超标未整改、未组织职业健康检查）、诉求（支付经济补偿 N + 办理离职手续 + 出具解除证明）
   - 落款日期即为解除日
3. **不要先停工**：发函后正常出勤（避免被乙方反咬"旷工"），直到乙方确认收到解除通知
4. **申请劳动仲裁**主张经济补偿：乙方收到解除通知后 30 日内未支付 N，向乙方注册地或工作地劳动仲裁委申请仲裁

**避雷**：
- ⚠️ **不要写"个人原因离职"**：写"个人原因"=放弃补偿，乙方的 HR 套路话术就是诱导你写这四个字
- ⚠️ **不要签"协商一致解除"**：除非补偿谈到位，否则第 38 条单方解除对你更有利（举证责任在乙方）
- ⚠️ **不要口头提离职**：必须书面，且明确援引第 38 条
- ⚠️ **保留交接清单**：正常交接，不留"未交接"把柄给乙方扣薪

### 5.3 终局三：违法解除 + 赔偿金 2N（被动反制）

**触发条件**：维权过程中，乙方**主动解除合同**（以"不胜任""违纪""组织调整"等理由辞退），而实际上是因为维权被打击报复。

**法律依据**：若乙方解除理由不成立（无法举证你不胜任/违纪），构成**违法解除**，依据《劳动合同法》第 48 条 + 第 87 条，可选择：
- 要求**继续履行合同**（恢复原岗原薪），或
- 要求**违法解除赔偿金 2N**（经济补偿标准的 2 倍）

**操作步骤**：
1. **拿到书面解除通知**：要求乙方出具书面《解除劳动合同通知书》，写明解除理由和依据
   - 乙方若拒不出具，录音+微信留痕，向劳动监察投诉"未出具解除证明"
2. **不要签任何"自愿离职""协商一致"文件**：签了就变主动离职，2N 没了
3. **立即固定"维权被打击"的证据链**：
   - 函告日期 vs 解除日期（时间相近，关联性强）
   - 行政投诉受理日期 vs 解除日期
   - 解除前的绩效/考勤记录（证明"不胜任/违纪"是莫须有）
   - 同期未维权的同事未被解除（证明选择性执法=报复）
4. **申请劳动仲裁**主张违法解除赔偿金 2N + 未休年假折算 + 未结清工资

**仲裁胜诉关键**：
- 举证"乙方解除理由不成立"——乙方需举证你不胜任/违纪，举证不能则败诉
- 举证"真实原因是维权报复"——用时间线 + 同事对比强化

### 5.4 终局决策树

```
乙方整改了吗？
├─ 是，且验收通过 → 终局一（改善留任）
└─ 否
   └─ 乙方主动解除你吗？
      ├─ 是 → 终局三（2N，被动反制）
      └─ 否，你想走吗？
         ├─ 想走 → 终局二（N，第38条主动解除）
         └─ 想留 → 继续施压（回到第三节，加码投诉+工会介入）
```

### 5.5 终局选择的实操建议

1. **团队不一定要同选一条终局**：有症状重、决心走的同事走终局二（N）；被乙方报复解除的同事走终局三（2N）；想留任的同事走终局一（验收留任）。各自独立但证据共享，互不影响。
2. **仲裁/诉讼成本预估**：
   - 劳动仲裁免费，审理期限 45-60 天
   - 一审诉讼费 10 元，简易程序 5 元
   - 时间成本：仲裁 2 个月 + 一审 3-6 个月 + 二审 3 个月（多数案件一审结案）
   - 律师费：劳动案件风险代理常见，可谈"胜诉后按补偿金额 10-20% 提成"
3. **证据保管清单**（贯穿全流程）：所有证据原件存保险柜/银行保管箱，扫描件云盘备份，**不要只存在公司电脑**（乙方可能远程注销账号）。

## 6. 核心原则回顾（贯穿全流程）

1. **每一步都在积累"乙方未履行劳动保护义务"的证据**——即便最终走不到仲裁，证据也是筹码
2. **不主动碰甲方**，让行政机关自行追溯——主战场始终是乙方
3. **不主动提离职**——除非走终局二且证据齐全
4. **不签任何"自愿""协商一致"文件**——签了 N/2N 全没
5. **集体行动 + 代表制**——避免被各个击破
