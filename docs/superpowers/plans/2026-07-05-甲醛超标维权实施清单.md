# 甲醛超标维权行动实施清单

> **For agentic workers:** 本清单不是代码任务，而是真人执行的法律维权行动步骤。逐项打勾跟踪进度，每步附"产出物"作为完成凭证。执行人需结合地方实施细则和个案情况调整。

**目标：** 在乙方驻场办公场所甲醛超标 1.5 倍（CMA 报告确认）的处境下，通过四阶段行动维护团队合法权益——争取改善+健康检查，或拿到 N/2N 经济补偿。

**策略骨架：** 证据固化 → 函告乙方设整改期 → 行政投诉双轨（卫健+人社） → 视乙方反应选终局（改善留任 / 38 条解除 N / 违法解除 2N）。每一步都积累"乙方未履行劳动保护义务"的证据。

**法律依据：** 《劳动法》第 54 条、《职业病防治法》第 35/39 条、《劳动合同法》第 38/48/87 条、GB/T 18883（甲醛 ≤0.10 mg/m³）、GBZ 2.1（甲醛 MAC 0.5 mg/m³）。

**关键认知：** 办公场景"超标 1.5 倍"通常指 0.15 mg/m³（相对 GB/T 18883），达不到 GBZ 2.1 的 0.5 mg/m³ 职业接触限值，大概率诊断不上职业病。维权重心放在"劳动保护权 + 行政投诉 + 第 38 条解除补偿"，不依赖职业病诊断。

### Task 2: CMA 报告核验与备份

**Files:**

- [ ] **Step 1: 拿到 CMA 报告原件**

```markdown

我们系[场地地址]驻场办公人员。贵机构于____年__月__日对该场所进行甲醛检测并出具报告（报告编号____），结论为甲醛超标 1.5 倍。
```

- [ ] **Step 2: 复印 3 份 + 扫描**

到复印店复印 3 份（分别存档/函告附件/行政投诉附件），原件扫描成 PDF 存云端+本地。

- [ ] **Step 3: 核对引用标准**

打开报告，查"检测依据"或"评价标准"栏：
- 若引用 **GB/T 18883**（≤0.10 mg/m³）→ 办公场景常见，浓度门槛定位"环境卫生超标"，走劳动保护权路径
- 若引用 **GBZ 2.1**（MAC 0.5 mg/m³）且测值 >0.5 → 职业接触超标，可同时走职业病诊断路径
- 把引用标准和测值记录到 `~/维权档案/01-证据/CMA报告/标准核验记录.md`

### Task 3: 现场二次取证

**Files:**
- Create: `~/维权档案/01-证据/现场照片视频/`

- [ ] **Step 1: 全员手机拍摄办公区全景**

把 CMA 报告原件摊在办公桌上，拍照让报告+桌面+日期（手机自带时间水印或另拍一张日历）同框，证明报告对应的就是这个场所。

- [ ] **Step 3: 录视频说明**

录制 1-2 分钟视频，代表出镜口述：
> "今天是 ____年__月__日，我是乙方[公司]派驻甲方[场地]的驻场员工[姓名]。我们办公场所经 CMA 检测甲醛超标 1.5 倍（展示报告），团队出现眼刺痛/咽痛/咳嗽等症状。现对现场状况录像取证。"

- 读数稳定后拍照
- 把测值记录到 `~/维权档案/01-证据/现场照片视频/复测记录.md`（日期、点位、测值、温度、湿度）

### Task 4: 医疗补证（关键短板）

**Files:**
- Create: `~/维权档案/01-证据/病历/[同事姓名]/`

- [ ] **Step 1: 有症状同事今天就就医**

挂三甲医院（不要去社区医院，证据效力弱）：
- 呼吸科（咳嗽/咽痛/胸闷）
- 耳鼻喉科（咽炎/鼻炎/眼刺激）
- 职业医学科（最对口，三甲医院有此科室的优先）

- [ ] **Step 2: 主诉模板**

就诊时按此主诉（不要省略甲醛暴露信息）：
> "医生，我在[场地地址]驻场办公，那里甲醛超标 1.5 倍（带 CMA 报告复印件）。我已经在那里办公 X 周，最近出现眼刺痛/咽痛/咳嗽/头晕 X 周，想查一下是不是甲醛引起的。"

- [ ] **Step 3: 要求病历写明三项**

请医生在病历上写明：
1. **症状**：具体症状及持续时间
2. **与甲醛暴露的关联性判断**：医生意见（如"考虑甲醛暴露所致上呼吸道刺激反应"）
3. **客观检查**：肺功能、眼结膜、血常规（至少做一项，留检查报告）

- [ ] **Step 4: 保留所有票据**

病历、检查报告、发票、挂号单**原件全部保留**，扫描存档到每人文件夹。

- [ ] **Step 5: 未就医同事做基线检查**

未出现症状的同事也去查一次（耳鼻喉+血常规），留基线数据。未来若出现迟发症状有对照，也能证明"全员受暴露影响"。

建 `~/维权档案/01-证据/病历/医疗证据汇总表.md`：

| 姓名 | 症状 | 就诊日期 | 医院 | 诊断 | 检查项 | 关联性判断 | 票据金额 |
|------|------|---------|------|------|--------|-----------|---------|
| ... | ... | ... | ... | ... | ... | ... | ... |

```markdown
2. 团队就医病历及票据复印件
```

| 推诿"甲方场地我们管不了" | 回函指出：用人单位义务不因场地是第三方而转移，法律依据不变，仍由乙方担责 |
| 报复性调岗/降薪/解除合同 | **不要主动提离职**。立即固定证据（书面调岗通知、降薪流水、解除通知），这是违法解除 2N 赔偿的标的，进入终局三 |
| 不回复 | 7 天期满直接进入第三阶段 |

- [ ] **Step 3: 7 天期满评估**

发函日起算 7 天后，评估乙方反应，决定是否进入第三阶段。如乙方已实质性整改，进入终局一验收；如未整改或拖延，进入第三阶段。

- 函告日期 vs 解除日期（时间相近，关联性强）
- 行政投诉受理日期 vs 解除日期
- 解除前的绩效/考勤记录（证明"不胜任/违纪"是莫须有）
- 同期未维权的同事未被解除（证明选择性执法=报复）

## 全流程核心原则（贯穿所有 Task）

1. **每一步都在积累"乙方未履行劳动保护义务"的证据**——即便最终走不到仲裁，证据也是筹码
2. **不主动碰甲方**，让行政机关自行追溯——主战场始终是乙方
3. **不主动提离职**——除非走终局二且证据齐全
4. **不签任何"自愿""协商一致"文件**——签了 N/2N 全没
5. **集体行动 + 代表制**——避免被各个击破
6. **证据原件存保险柜/银行保管箱，扫描件云盘备份，不要只存在公司电脑**——乙方可能远程注销账号
