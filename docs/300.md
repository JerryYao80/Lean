# 过去一年涨幅前300 vs 沪深300成分股重叠分析

## 分析方法

- **数据来源**: tushare_data 本地 Parquet 数据（daily + adj_factor）
- **时间范围**: 2025-06-05 ~ 2026-06-05（约1年）
- **收益率计算**: 复权收盘价涨跌幅 = (期末复权价 / 期初复权价 - 1) × 100%
- **沪深300成分股**: tushare `index_weight` API，index_code=000300.SH，2026-06-01 数据（300只）
- **有效股票数**: 5527 只（有足够数据的 A 股）

## 结论

**过去一年涨幅最大的前 300 支股票中，有 16 支是沪深 300 成分股，占比 5.3%。**

这意味着涨幅靠前的股票绝大多数不在沪深300成分股中，小盘股/非指数股在过去一年显著跑赢大盘蓝筹。

## 解读

1. **极低重叠率（5.3%）**: 沪深300成分股仅 16/300 进入涨幅前300，远低于随机期望的 300/5527 ≈ 5.4%，几乎等于随机水平
2. **涨幅分布极度偏斜**: 前300名涨幅最低也有 186%，而沪深300成分股涨幅中位数远低于此
3. **小盘效应显著**: 涨幅靠前的股票多为中小市值（688/300/301 开头），沪深300的大盘蓝筹难以进入涨幅榜前列
4. **幸存者偏差**: 此分析仅包含当前存续股票，已退市股票未纳入
