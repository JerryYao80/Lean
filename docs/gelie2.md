# 因子量化中 Alpha 与 Portfolio 割裂问题 — 为什么至今未解决

## 割裂是一直有的吗？

**是的，从 LEAN 第一个 BL 模型就有了，而且不是 LEAN 独有的问题——所有因子量化框架都存在。**

## LEAN 为什么没解决？

**因为 LEAN 认为这不是它该解决的问题。** 原因有三层：

### 1. LEAN 的定位是引擎，不是策略

LEAN 提供的是**通用基础设施**：数据加载、事件驱动、订单执行、回测框架。它的 BL 模型是一个**通用组件**，设计目标是：

- 美股 Long/Short 对冲基金用
- 配合任意 Alpha 模型（技术指标、基本面、情绪等）
- 不绑定任何特定因子体系

如果 LEAN 在 BL 模型里内置 Barra 因子协方差，那它就变成了**Barra 专用引擎**，其他策略（ETF轮动、配对交易、CTA）都用不了。所以 LEAN 选择提供**最通用的接口**（`IPortfolioOptimizer`、`IPortfolioConstructionModel`），让用户自己注入风险模型。

### 2. 通用 BL 模型的设计假设

LEAN 原生 BL 的设计假设是：

```
Alpha 层输出 → Insight(方向+幅度) → BL 自动配权
```

这个假设在**单因子 Alpha 或纯方向性 Alpha** 下是合理的——比如一个 RSI AlphaModel 只输出"看多/看空"，BL 用价格协方差配权没有割裂问题，因为 Alpha 层本身就没有因子风险的概念。

**割裂只在 Alpha 层也是因子模型时才出现**——你用因子选股，但用价格协方差配权，两套语言不一致。这是 LEAN 没有预见的用例。

### 3. 实际影响可能没有理论那么大

这是最诚实的部分：**解决了割裂，回测效果未必显著提升。**

| 论点 | 说明 |
|---|---|
| 理论上应该更好 | 因子模型协方差参数少、估计准、与Alpha一致 |
| 实践中提升有限 | 对于 25 只 long-only 股票，样本协方差虽粗糙但"够用" |
| 学术证据混合 | Clarke de Silva Thorley (2006) 显示因子协方差优于样本协方差，但改进幅度在 Sharpe 上通常 <0.1 |
| 风险收益不对称 | 实现因子协方差的工程成本高，但边际改进小 |

这也是为什么**业界很多量化团队也还在用样本协方差或 Ledoit-Wolf 压缩**——不是不知道割裂，而是 ROI 不够。

## 所以现在该不该解决？

| | 解决割裂 | 不解决，用 Ledoit-Wolf 压缩 |
|---|---|---|
| 工程量 | 大（自定义 BL + 因子暴露注入） | 小（~50行替换协方差计算） |
| 学术正确性 | ✅ 最正确 | ⚠️ 折中但实用 |
| 实际收益提升 | 可能 <0.1 Sharpe | 可能 <0.05 Sharpe |
| 风险 | 引入新的实现bug | 低 |
| 可解释性 | ✅ 风险来源可追溯 | 一般 |

**务实建议**：先做 Ledoit-Wolf 压缩（docs/3.md 中的第2优先级），成本低、收益确定、解决样本协方差的数值不稳定问题。割裂问题记录在 `docs/gelie.md` 中作为架构演进方向，但不急于现在实现——因为当前 25 只股票 + 月度调仓的场景下，样本协方差的问题被 Ledoit-Wolf 压缩已经大幅缓解，因子协方差的边际收益不值得它的工程成本。
