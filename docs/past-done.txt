一、我们长期在做什么
本项目是在 LEAN 上落地 A 股量化策略，重点有三类：
1. Barra CNE5 策略
2. A 股 LLM 选股策略
3. T+0 ETF 策略
4. 行业轮动策略

核心目标不是做研究原型，而是把下面这条链路真正打通并长期稳定：
实时日线接入 -> 策略调度/特征或计划文件刷新 -> 标准 LEAN backtest/live-paper -> 结果可追踪 -> 风险可管控

二、用户的明确偏好和硬约束
1. 必须优先走标准 LEAN 流程，不要自定义替代回测/模拟框架。
2. live paper 需要尽量透明，不能黑盒。
3. 后来用户要求暂时关闭自定义的 account summary / trade executions / portfolio allocation 三张表，改回原生无券商 LEAN live-paper 输出。
4. 实时日线来自 Tushare 的 rt_k / rt_etf_k，不是历史 parquet。
5. 现在各策略 live-paper 的共同流程应固定为：
   全市场实时日线接入 -> 各策略按自己的 universe 过滤 -> 生成策略输入（特征/因子/计划）-> 标准 LEAN live-paper 输出
6. dotnet 路径不是系统默认，必须按：
   /usr/local/dotnet/dotnet
7. Python 最稳环境是：
   /root/miniconda3/envs/quant311/bin/python
