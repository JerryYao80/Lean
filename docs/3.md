# Portfolio Construction 改进分析

## 当前 V4.2 BL 流程

```
Alpha 输出 Insight(Magnitude, Direction, Confidence)
        │
        ▼
① 构建观点矩阵 P, Q
   P: 每个 SourceModel 一行, 值 = direction × |magnitude| / Q_sum
   Q: 每个 SourceModel 的 max(上行magnitude之和, 下行magnitude之和)
        │
        ▼
② 历史收益率矩阵 R (63天 × N只)
   来自 OnSecuritiesChanged() 加载的 History() 数据
   ReturnsSymbolData 维护 ROC + RollingWindow
        │
        ▼
③ 均衡收益 Π 和协方差 Σ
   Π = Σ · w_eq · riskAversion   (w_eq = 等权)
   Σ = R.Covariance() × 252     (年化协方差)
        │
        ▼
④ BL 后验公式
   Ω = diag(τ·P·Σ·P')          观点不确定度
   A = τΣ·P'·(P·τΣ·P' + Ω)⁻¹
   Π_BL = Π + A·(Q - P·Π)      后验期望收益
   Σ_BL = (Σ + M)·δ             后验协方差
        │
        ▼
⑤ MaximumSharpeRatio 优化
   min w'Σw  s.t. (Π_BL-rf)'w = k, Σw = 1, 0≤w≤1
   → 输出权重 W[]
```

## 五个改进空间

### 1. 均衡收益用等权先验 — 不合理

**问题**：`GetEquilibriumReturns()` 用 `w_eq = 1/N` 等权，隐含假设"市场组合是等权的"。但 A 股 CSI300 的市值分布极度不均（茅台 vs 小盘股），等权先验偏离真实市场组合。

**改进**：用**市值加权**作为均衡先验，更接近真实的 CAPM 隐含收益。V2 SignalModel 的 BL 就用了 `BuildPriorWeights(selected, factors, useMarketCap: true)`。

**难度**：低。因子数据中已有 `total_mv`，只需在 `GetEquilibriumReturns()` 中替换 `W = Vector.Create(N, 1.0/N)` 为市值权重。

### 2. 协方差估计用简单样本协方差 — 不稳定

**问题**：`Σ = returns.Covariance().Multiply(252)` 是最朴素的样本协方差。

BL 优化器的 N 取决于当期活跃 Insight 的标的数（由 AlphaModel 的 topN 决定，默认 25），
不是全市场 5000 只。T 取决于 `black-litterman-period` 参数（默认 63 个交易日，可配置为 252/756 等）。

| 场景 | N (标的) | T (天数) | T/N | 稳定性 |
|---|---|---|---|---|
| 当前默认 (topN=25, period=63) | 25 | 63 | 2.5x | 勉强可用 |
| topN=50, period=63 | 50 | 63 | 1.3x | 不稳定 |
| topN=100, period=63 | 100 | 63 | 0.6x | 奇异矩阵，无法求逆 |
| topN=25, period=252 | 25 | 252 | 10x | 很稳定 |
| topN=25, period=756 | 25 | 756 | 30x | 极稳定但滞后 |

当 T/N < 3 时，样本协方差矩阵是**近奇异的**，特征值不稳定，Cholesky 分解可能失败，
BL 后验的逆矩阵不可靠。即使 T/N ≥ 3，样本协方差的估计噪声仍然很大。

**改进**：用 **Ledoit-Wolf 压缩估计**，将样本协方差向对角矩阵（或常数相关矩阵）收缩：

```
Σ_shrunk = α · Σ_sample + (1-α) · F
```

其中 F 是结构化先验（如对角矩阵或单因子模型），α 由 Ledoit-Wolf 公式最优确定。这在量化投资中是标准做法。

**难度**：中。需实现 Ledoit-Wolf 公式（~50 行 C#），替换 `returns.Covariance()`。

### 3. 观点矩阵构建方式粗糙

**问题**：`TryGetViews()` 把所有 Insight 按一个 `SourceModel` 分成一行观点。V4.2 只有一个 AlphaModel，所以 P 矩阵只有 **1 行**。这意味着 BL 后验实际上退化为一个**标量融合**——把所有 25 只股票的观点用一个标量 Q 混合，信息损失严重。

**改进**：将每只股票作为独立观点（P 为 25×25 单位矩阵的子集，Q 为每只股票的 Magnitude），或按因子暴露分组构建观点。这是 Barra 原始 BL 论文的推荐方式。

**难度**：中。需要自定义 `IPortfolioConstructionModel` 或继承后 override `TryGetViews()`。

### 4. 没有换手率约束

**问题**：当前 BL 优化器只约束权重范围 [0, 1] 和 Σw = 1。没有换手率约束意味着每月调仓时可能产生极大的交易量，实际执行中摩擦成本高。

**改进**：在优化问题中加入换手率惩罚项或约束：

```
min w'Σw + λ·||w - w_prev||²
s.t. Σw = 1, 0 ≤ w ≤ 1
```

**难度**：中。需自定义 `IPortfolioOptimizer`，在目标函数中加 L2 惩罚项。

### 5. 风险模型与 Alpha 模型割裂

**问题**：BL 用**价格收益率协方差**（63 天日收益率的 sample covariance），但 Alpha 层用的是**因子模型**（15 个 Barra 因子）。这是两套不同的风险模型，可能导致：
- BL 协方差捕捉的因子暴露和 Alpha 选股的因子暴露不一致
- 协方差中包含 Alpha 层已对冲的风险因子

**改进**：用**因子模型协方差**替代样本协方差：

```
Σ_factor = B·Σ_f·B' + D
```

B = 因子暴露矩阵，Σ_f = 因子协方差，D = 特质收益协方差（对角阵）。这正是 Barra USE4/CNE5 的风险模型核心。

**难度**：高。需要在 BL 模型中注入因子暴露矩阵和因子协方差，替代 `returns.Covariance()`。

## 优先级排序

| 优先级 | 改进 | 预期收益 | 难度 | 风险 |
|---|---|---|---|---|
| 🥇 | 市值加权先验 | 中 | 低 | 低 |
| 🥈 | Ledoit-Wolf 压缩协方差 | 高 | 中 | 低 |
| 🥉 | 换手率约束 | 中 | 中 | 低 |
| 4 | 观点矩阵细化 | 高 | 中 | 中 |
| 5 | 因子模型协方差 | 最高 | 高 | 中 |

前三个可以立即实施，后两个需要较大改动。
