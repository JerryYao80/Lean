# Barra CNE5 V3 优化方法数据可用性评估

评估 12 个优化方法所需数据是否可从 tushare_data 获取，以及是否需要额外数据源。

---

## 一、完全可从 tushare 获取（无需额外数据）

以下 9 个方法全部基于已有的日频行情和因子数据，无需任何额外数据源。

| 优化方法 | 所需数据 | tushare 数据源 | 当前使用状态 |
|---------|---------|---------------|-------------|
| **因子动量** | 因子历史收益 | `daily` + `index_daily` | V1 因子构建已使用 |
| **因子 IC 滚动窗口** | 因子值 + 下期收益 | `daily` | V1 因子构建已使用 |
| **波动率目标** | 组合日收益 | `daily` | V1 因子构建已使用 |
| **条件 VaR / CVaR** | 历史日收益率 | `daily` | V1 因子构建已使用 |
| **泊松跳跃过程** | 日收益率序列 | `daily` | V1 因子构建已使用 |
| **回撤路径管理** | 组合净值曲线 | LEAN 引擎原生提供 | 无需 tushare |
| **协方差收缩估计** | 收益率协方差 | `daily` | V1 因子构建已使用 |
| **换手率约束** | 前期持仓权重 | LEAN 引擎原生提供 | 无需 tushare |
| **因子正交化增强** | 因子截面数据 | `AShareBarraCNE5V2FactorData` | V2 因子数据已使用 |

## 二、可从 tushare 获取但尚未在因子构建中使用

数据已在磁盘下载，但当前无因子构建脚本消费。

| 优化方法 | 所需数据 | tushare API | 磁盘数据 | 当前使用状态 |
|---------|---------|------------|---------|-------------|
| **体制切换（简单规则版）** | 沪深300波动率 | `index_daily` | 已下载 | V1 因子构建已使用（beta 计算），可直接复用 |
| **体制切换（HMM版）** | 行业/概念指数 | `sw_daily`（申万）、`ths_daily`（同花顺） | 已下载 | 未被任何因子构建脚本使用 |
| **因子拥挤度** | 公募持仓 | `fund_portfolio` | 已下载（150个季度目录） | 未被任何脚本消费 |
| **因子拥挤度** | 北向持仓 | `hk_hold` | 已下载 | V2 因子构建已使用（HKRATIO） |
| **因子拥挤度** | 融资融券 | `margin_detail` | 已下载（11001个目录） | V2 因子构建已使用（MGRATIO/MGCHANGE） |
| **分层选股** | 申万行业分类映射 | `index_classify` + `index_member` | 已下载 | 未被任何因子构建脚本使用 |

### 2.1 体制切换数据详情

简单规则版仅需沪深300指数日行情（`index_daily`），已有完整数据。

HMM 版可扩展使用：
- **申万行业指数**：`sw_daily` + `index_classify` + `index_member`（行业收益率用于多维度体制识别）
- **同花顺概念指数**：`ths_daily` + `ths_index` + `ths_member`（主题轮动信号）
- **中信行业指数**：`ci_daily` + `ci_index_member`（备选行业分类）

### 2.2 因子拥挤度数据详情

三个维度数据均已在磁盘：

| 维度 | API | 字段 | 粒度 | 频率 | 备注 |
|------|-----|------|------|------|------|
| 外资持仓 | `hk_hold` | ratio | 个股 | 日频 | 已在 V2 使用 |
| 杠杆资金 | `margin_detail` | rzye, rqye, rzmre | 个股 | 日频 | 已在 V2 使用 |
| 公募持仓 | `fund_portfolio` | stk_mkv_vol, stk_mkv_ratio | 个股-基金 | 季频 | **未使用**，需注意季频滞后 |

`fund_portfolio` 的接入注意事项：
- 数据频率为季报，发布有 1-2 个月滞后
- 建议用上期持仓 forward-fill 到当期
- 可结合 `top10_holders` / `top10_floatholders` 补充前十大股东变化

### 2.3 分层选股数据详情

申万行业分类体系完整可用：

| 数据 | API | 说明 |
|------|-----|------|
| 行业分类 | `index_classify` | 申万一/二/三级行业列表 |
| 成分映射 | `index_member` | 股票→行业映射关系 |
| 行业行情 | `sw_daily` | 行业指数日行情 |
| 行业权重 | `index_weight` | 行业成分权重 |

备选行业分类：同花顺（`ths_index`/`ths_member`）、中信（`ci_index_member`）

## 三、无法从 tushare 获取，需额外数据源

| 优化方法 | 缺失数据 | tushare 限制 | 替代方案 |
|---------|---------|-------------|---------|
| **补齐分析师预期因子（EPIBS/EGIBS）** | 一致预期 EPS/PE/长期增长率 | tushare 仅有 `report_rc`（单篇研报），无预聚合一致预期 | 项目已有合成数据 `local_data/analyst_estimates/synthetic_consensus_estimates.csv`，可直接接入 |
| **高频因子（VPIN、订单流不平衡）** | 分钟/Tick 级历史数据 | `stk_mins` 需 10000+ 积分，当前不可用 | 仅有实时 `rt_min` 接口，无法做历史回测；可考虑从其他数据源购买或用日线近似 |
| **另类数据因子（新闻情感、卫星、供应链）** | NLP 情感得分、供应链关系等 | tushare 不提供 | 项目已有 GDELT 新闻情感数据（`Data/alternative/gdelt-news-sentiment/`），可扩展接入 |

### 3.1 分析师预期因子替代方案

tushare `report_rc` 包含个股研报的 EPS/PE 预测，但不是一致预期。可行路径：

1. **使用已有合成数据**：`local_data/analyst_estimates/synthetic_consensus_estimates.csv` 已存在，可直接作为 custom data 接入
2. **自行聚合 report_rc**：按股票+日期对多份研报的 EPS 预测取加权均值，权重视券商覆盖度和时效性
3. **东方财富一致预期**：如需更准确数据，可从东方财富网页爬取（非 tushare）

### 3.2 高频因子替代方案

由于历史分钟数据不可得，可考虑：

1. **用日线近似微观结构**：用日内振幅（high-low）/成交量比替代 VPIN
2. **仅实时阶段使用高频因子**：实盘通过 `rt_min` 获取分钟数据，回测阶段跳过
3. **购买第三方数据**：如 Wind 分钟数据、聚宽 JoinQuant 分钟数据

### 3.3 另类数据因子替代方案

| 数据类型 | 可行来源 | 接入难度 |
|---------|---------|---------|
| 新闻情感 | GDELT（已接入）+ tushare `cctv_news`（已下载未使用） | 低 |
| 舆情热度 | tushare `ths_hot` / `dc_hot`（已下载未使用） | 低 |
| 龙虎榜/游资 | tushare `top_list` / `top_inst` / `hm_detail`（已下载未使用） | 低 |
| 供应链关系 | 不可从 tushare 获取 | 高 |
| 卫星/遥感 | 不可从 tushare 获取 | 高 |

## 四、汇总评估

### 按实施阶段

| 阶段 | 优化方法 | 数据是否就绪 | 备注 |
|------|---------|-------------|------|
| **阶段1** | OOS 因子权重校准 | 就绪 | 纯算法，无额外数据需求 |
| **阶段1** | IC/IR 因子有效性监控 | 就绪 | 从 daily 收益计算 |
| **阶段1** | 补齐分析师预期因子 | **部分就绪** | 合成数据已有，report_rc 可自行聚合 |
| **阶段2** | 因子动量/IC滚动权重 | 就绪 | 从已有因子数据计算 |
| **阶段2** | 波动率目标仓位管理 | 就绪 | 从 daily 收益计算 |
| **阶段2** | 换手率约束 + 协方差收缩 | 就绪 | LEAN 原生 + daily 收益 |
| **阶段3** | 体制切换动态权重 | 就绪 | index_daily 已有；HMM版行业指数已下载未接入 |
| **阶段3** | 泊松跳跃尾部风险模型 | 就绪 | 从 daily 收益估计跳跃参数 |
| **阶段3** | 分层选股 + 因子正交化 | 就绪 | 申万行业分类已下载未接入 |

### 按数据可用性

| 类别 | 方法数量 | 占比 |
|------|---------|------|
| 完全可从现有 tushare 数据实现 | 9 | 75% |
| 数据已在磁盘但未接入因子构建 | 2 | 17% |
| 受限于 tushare 积分/无此数据 | 1 | 8% |

**结论**：12 个优化方法中，9 个完全可从现有 tushare 数据实现，2 个数据已在磁盘但未接入（体制切换行业指数、因子拥挤度 fund_portfolio），仅高频因子受限于 tushare 积分门槛。所有三个阶段的实施不存在数据瓶颈。
