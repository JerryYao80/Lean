# LEAN 原生选股与择时框架

LEAN 原生有完整的选股和择时框架，基于五层架构。

## 选股（Universe Selection）

| 模型 | 用途 |
|------|------|
| `CoarseFundamentalUniverseSelectionModel` | 按成交额/价格筛选（粗选） |
| `FineFundamentalUniverseSelectionModel` | 按基本面数据精选（两阶段 coarse+fine） |
| `EmaCrossUniverseSelectionModel` | 按 EMA 交叉动量选股（选股+择时混合） |
| `QC500UniverseSelectionModel` | 按成交额选 Top 500 |
| `ETFConstituentsUniverseSelectionModel` | 选 ETF 成分股 |
| `FundamentalUniverseSelectionModel` | 基本面选股基类 |

## 择时（Alpha Models）

| 模型 | 用途 |
|------|------|
| `EmaCrossAlphaModel` | 快慢 EMA 交叉 |
| `MacdAlphaModel` | MACD 信号线交叉 |
| `RsiAlphaModel` | RSI 超买超卖 |
| `HistoricalReturnsAlphaModel` | 历史收益率动量 |
| `PearsonCorrelationPairsTradingAlphaModel` | 配对交易 |
| `ConstantAlphaModel` | 常量信号 |
| `CompositeAlphaModel` | 组合多个 Alpha 模型 |

## 权重分配（Portfolio Construction）

| 模型 | 用途 |
|------|------|
| `EqualWeightingPortfolioConstructionModel` | 等权分配 |
| `ConfidenceWeightingPortfolioConstructionModel` | 按 Insight 置信度加权 |
| `InsightWeightingPortfolioConstructionModel` | 按 Insight 权重加权 |
| `MeanVarianceOptimizationPortfolioConstructionModel` | 均值方差优化 |
| `BlackLittermanOptimizationPortfolioConstructionModel` | Black-Litterman |
| `RiskParityPortfolioConstructionModel` | 风险平价 |
| `SectorWeightingPortfolioConstructionModel` | 行业加权 |
| `MeanReversionPortfolioConstructionModel` | 均值回归 |
| `AccumulativeInsightPortfolioConstructionModel` | 累积 Insight 权重 |

### 优化器（Portfolio Optimizers）

| 优化器 | 用途 |
|--------|------|
| `MaximumSharpeRatioPortfolioOptimizer` | 最大化 Sharpe Ratio |
| `MinimumVariancePortfolioOptimizer` | 最小化方差 |
| `RiskParityPortfolioOptimizer` | 风险平价优化 |
| `UnconstrainedMeanVariancePortfolioOptimizer` | 无约束均值方差优化 |

## 风控（Risk Management）

| 模型 | 用途 |
|------|------|
| `MaximumDrawdownPercentPerSecurity` | 单证券最大回撤平仓 |
| `MaximumDrawdownPercentPortfolio` | 组合最大回撤平仓 |
| `TrailingStopRiskManagementModel` | 移动止损 |
| `MaximumUnrealizedProfitPercentPerSecurity` | 单证券最大浮盈平仓 |
| `MaximumSectorExposureRiskManagementModel` | 行业暴露度限制 |
| `CompositeRiskManagementModel` | 组合多个风控模型 |

## 执行（Execution）

| 模型 | 用途 |
|------|------|
| `ImmediateExecutionModel` | 立即市价执行 |
| `SpreadExecutionModel` | 价差范围内执行 |
| `StandardDeviationExecutionModel` | 按价格标准差缩量执行 |
| `VolumeWeightedAveragePriceExecutionModel` | VWAP 执行 |

## ETF 宇宙定义（预定义 ETF 组合）

| 定义 | 用途 |
|------|------|
| `LiquidETFUniverse` | 高流动性 ETF |
| `EnergyETFUniverse` | 能源行业 ETF（XLE, IYE, VDE 等） |
| `TechnologyETFUniverse` | 科技行业 ETF（XLK, QQQ, SOXX 等） |
| `MetalsETFUniverse` | 金属 ETF（GLD, IAU, SLV 等） |
| `SP500SectorsETFUniverse` | SP500 行业 ETF（XLB, XLE, XLF 等） |
| `USTreasuriesETFUniverse` | 美国国债 ETF（IEF, SHY, TLT 等） |
| `VolatilityETFUniverse` | 波动率 ETF（SQQQ, TQQQ, TVIX 等） |

## 使用方式

通过 `QCAlgorithm` 的 Set 方法组合各层模型：

```csharp
SetUniverseSelection(new CoarseFundamentalUniverseSelectionModel(CoarseSelection));
SetAlpha(new EmaCrossAlphaModel());
SetPortfolioConstruction(new MeanVarianceOptimizationPortfolioConstructionModel());
SetRiskManagement(new MaximumDrawdownPercentPerSecurity(0.05m));
SetExecution(new ImmediateExecutionModel());
```

## A 股适配注意

以上模型均针对美股设计，A 股使用时需适配：
- T+1 结算规则（`AShareT1Holding` + `AShareT1PortfolioModel`）
- 涨跌停限制（`AShareStockFillModel`）
- 100 股手数规则（`AShareStockBuyingPowerModel`）
- A 股手续费（`AShareStockFeeModel`）
