# 社保基金持仓 — 散户投资价值筛选

从过去一年涨幅前 500 的股票中，通过 tushare `top10_holders` 接口检索社保基金（全国社保/社保基金组合）持仓，筛选**价格适中（≤50 元）、短期动能向上、基本面有支撑**的标的。

## 筛选条件

| 条件 | 阈值 | 理由 |
|------|------|------|
| 社保持仓 | 十大股东中出现社保基金组合 | 社保选股代表机构认可度 |
| 股价 | ≤ 50 元 | 散户可参与 |
| 近 1 月涨幅 | > 0 | 短期趋势仍向上 |
| 板块 | 排除科创板(688)/北交所(920) | 门槛高或流动性差 |
| 基本面 | 有盈利 | 排除亏损股 |

## 五、散户操作建议

### 资金分配参考（5 万元为例）

| 标的 | 分配 | 股数 | 金额 | 逻辑 |
|------|------|------|------|------|
| 可立克 | 1.5 万 | 500 股 | 13,005 | ROE 最高 + 净利增长最强 |
| 冰轮环境 | 1.5 万 | 400 股 | 12,416 | 高毛利 + 高净利 + 综合最佳 |
| 艾华集团 | 1 万 | 200 股 | 7,100 | 短期动能最强 + 低负债 |
| 科士达 | 1 万 | 200 股 | 10,180 | 双增长 + 社保持仓最集中 |

### 买入时机

- **可立克**：1 月涨幅 +27% 仍在上行，可逢回调至 24 元附近建仓
- **艾华集团**：1 月 +67% 涨幅过大，建议等回踩至 30-32 元区间再入
- **冰轮环境**：1 月 +19% 温和上涨，可在 30 元整数关口附近试探
- **科士达**：近 3 月横盘(+0.4%)，50 元附近可分批布局

### 止损纪律

- 单只亏损 **10%** 无条件止损
- 社保持仓并非保底信号，仅代表机构看好方向
- **分散持仓**，严禁满仓单只，单只占比不超过 30%

### 关注信号

- **社保持仓变动**：每季度财报披露后查看十大股东变化，社保减持应及时跟出
- **社保17022 组合**（汇添富管理）同时持有冰轮环境和科士达，如果该组合持续增持则信号更强
