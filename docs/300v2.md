# 过去一年涨幅前300 vs 主要指数成分股重叠分析

## 分析方法

- **数据来源**: tushare_data 本地 Parquet（daily + adj_factor）+ tushare `index_weight` API
- **时间范围**: 2025-06-05 ~ 2026-06-05（约1年）
- **收益率计算**: 复权收盘价涨跌幅 = (期末复权价 / 期初复权价 - 1) × 100%
- **有效股票数**: 5527 只 A 股
- **指数成分股日期**: 沪深300 为 2026-06-01 快照，其余指数为 2025-03-31 快照（API 数据可用性限制）

**过去一年涨幅最大的前 300 支股票中，有 16 支是沪深300成分股，占比 5.3%。**

## 五、解读

1. **沪深300极度缺席**: 仅 16/300（5.3%）进入涨幅榜，几乎等于随机水平（300/5527=5.4%），说明大盘蓝筹过去一年几乎没有超额收益
2. **涨幅集中在指数外**: 42%（126只）的涨幅领先股票不属于任何主要指数，这些是小盘股或尚未被纳入指数的新兴公司
3. **创业板50渗透率最高**: 18% 的创业板50成分股进入 Top300，创业板龙头是涨幅主力
