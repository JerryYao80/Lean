# AIDC（AI 数据中心）概念股 — 散户投资价值筛选

### 买入时机

- **冰轮环境**：1 月 +18% 温和上涨，可在 30 元整数关口附近建仓
- **中兴通讯**：1 月仅 +1% 横盘，39 元附近可分批布局，适合中长线
- **隆华科技**：11-12 元区间可试探，等放量突破 12 元再加仓

### 止损纪律

- 单只亏损 **10%** 无条件止损
- AIDC 概念股波动率极高（日均振幅 3-8%），**严禁满仓单只**
- 关注北美云厂商资本开支数据（季度财报），若资本开支增速放缓则 AIDC 景气度下行

### 关键观测指标

- **液冷渗透率**：2026 年智算中心液冷标配率是否达到 76%
- **光模块出货量**：800G/1.6T 光模块季度出货数据（中际旭创财报）
- **北美 Capex**：Meta/Google/Amazon/Microsoft 季度资本开支
- **国内算力建设**：六大算力集群节点建设进度
