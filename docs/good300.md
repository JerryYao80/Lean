# Top300 中低价强势股筛选

从过去一年涨幅前 300 的股票中，筛选**价格低（≤30 元）、增长强劲、基本面有支撑、适合散户小资金参与**的标的。

## 筛选条件

| 条件 | 阈值 | 理由 |
|------|------|------|
| 股价 | ≤ 30 元 | 1 手 100 股 ≤ 3000 元，小资金可参与 |
| 近 1 月涨幅 | > 0 | 短期趋势仍向上 |
| 近 3 月涨幅 | > 20% | 中期动能充足 |
| 近 1 周跌幅 | < 5% | 未在急跌中 |
| 科创板/北交所 | 排除 | 688 开头需 50 万门槛，920 流动性差 |
