# 风险模型与 Alpha 模型割裂 — 详解

## 当前 V4.2 的两条平行轨道

V4.2 内部实际上有**两套完全独立的风险模型**在并行运作，它们互不知晓：

```
┌─────────────────────────────────────────────────────┐
│  Alpha 层 (AShareBarraCNE5V4_2AlphaModel)           │
│                                                      │
│  风险认知：15个Barra因子                              │
│  "我知道momentum高风险，quality低风险"                 │
│  "我用因子权重 -0.10 控制 resvol 暴露"                │
│  "我用 regime 切换应对市场状态变化"                     │
│                                                      │
│  输出：Insight(每只股票一个Magnitude)                  │
└──────────────────────┬──────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────┐
│  Portfolio 层 (BlackLitterman...)                    │
│                                                      │
│  风险认知：63天价格收益率协方差矩阵                    │
│  "我不知道什么叫momentum或quality"                     │
│  "我根据历史收益率算出一个25×25的Σ"                    │
│  "我的Σ里包含了所有风险来源，但我不区分它们"             │
│                                                      │
│  输出：权重 W[]                                      │
└─────────────────────────────────────────────────────┘
```

**这就是割裂**：Alpha 层用因子语言思考风险，Portfolio 层用价格协方差语言思考风险。两者对"什么是风险"的理解不一致。

## 具体问题一：协方差中包含 Alpha 已对冲的风险

假设 Alpha 层判断：当前高波动环境下，residual volatility 是坏东西，给了 `resvol` **负权重 -0.15**。这意味着 Alpha 层**有意回避**高 resvol 的股票。

但 Portfolio 层不知道这件事。它看 63 天收益率协方差，发现高 resvol 的股票之间相关性高，于是 BL 优化器可能：

```
"这些高 resvol 股票相关性高，但它们的 BL 后验收益也很高（因为 Alpha 给了高综合分），
 那我就多配它们吧" → 实际上增加了 Alpha 层想回避的风险暴露
```

Alpha 层努力用 -0.15 权重压低的 resvol 暴露，被 BL 优化器在协方差盲区中**悄悄加回来了**。

## 具体问题二：协方差无法区分共同因子风险和特质风险

样本协方差 `Σ = R.Covariance()×252` 是一个黑箱。假设茅台和五粮液收益率相关性 ρ=0.7，这个 0.7 来自哪里？

```
ρ(茅台, 五粮液) = 0.7
 ├── 因为都是白酒行业（行业因子）       ≈ 0.3
 ├── 因为都是大盘股（size因子）         ≈ 0.2
 ├── 因为市场 beta 相近（beta因子）     ≈ 0.15
 └── 特质相关（品牌联动等）            ≈ 0.05
```

Alpha 层知道前三者是**因子风险**（可控，已通过因子权重管理），只有最后一个是**特质风险**（不可分散）。但 BL 的样本协方差把 0.7 全部当作一个数字，优化器无法区分：

- 如果 Alpha 层减配白酒行业（行业因子负暴露），BL 优化器可能因为 0.7 的高相关反而把白酒股配在一起
- 如果市场 beta 突然变化（regime 切换），样本协方差有 63 天滞后，无法及时反映

## 具体问题三：结构化协方差 vs 样本协方差的数学对比

Barra 因子模型协方差将风险**分解**为两层：

```
Σ_factor = B · Σ_f · B' + D
            ↑              ↑
       因子贡献的风险    特质风险
       (可解释、可控)    (残差、需分散)
```

| | 样本协方差 | 因子模型协方差 |
|---|---|---|
| 维度 | N×N = 25×25 | B: 25×15, Σ_f: 15×15, D: 25×25(对角) |
| 需估计参数 | N(N+1)/2 = 325 | 15×16/2 + 25 = 145 |
| 结构 | 无结构（纯数据驱动） | 有层次（因子+特质） |
| 可解释性 | ❌ 看不出风险来源 | ✅ 每个风险来源可追溯 |
| 稳定性 | 差（T/N小时奇异） | 好（参数少，估计更准） |
| 与Alpha一致性 | ❌ 完全独立 | ✅ 用同一套因子体系 |

参数少 = 估计更准 = 协方差更稳定 = BL 后验更可靠。

## 具体问题四：用数字说话

假设 V4.2 选出 25 只股票，当前 BL 用 63 天数据：

**样本协方差**需要估计 325 个参数（25×24/2），但只有 63×25=1575 个数据点。每个参数平均只有 4.8 个自由度，估计噪声极大。

**因子模型协方差**需要估计：
- Σ_f: 15×16/2 = 120 个参数（因子间协方差）
- D: 25 个参数（每只股票的特质方差）
- B: 25×15 = 375 个参数（因子暴露，但这是**已知的**——来自 Barra 因子数据）

真正需要从数据估计的只有 120 + 25 = **145 个参数**，自由度比 325→145 提升 2.2 倍。

## 改进方案：因子模型协方差注入 BL

```
当前：
  Σ = returns.Covariance() × 252          ← 样本协方差（黑箱）

改进：
  B = [每只股票的15个因子暴露值]            ← 从 FactorData 直接取
  Σ_f = 因子收益率的协方差 (15×15)          ← 用因子时间序列估计，参数少
  D = diag(特质收益方差)                    ← 回归残差的方差
  Σ = B · Σ_f · B' + D                    ← 因子模型协方差（有结构）
```

具体实现：

```
1. 对每只股票 s，回归：r_s = α_s + β_s1·f1 + β_s2·f2 + ... + β_s15·f15 + ε_s
   → 得到 B[s,:] = [β_s1, β_s2, ..., β_s15]
   → 得到 D[s,s] = Var(ε_s)

2. 计算因子时间序列的协方差：Σ_f = Cov([f1, f2, ..., f15])

3. 组装：Σ = B · Σ_f · B' + D

4. 替换 BL 中的 returns.Covariance() × 252
```

## 为什么难度高

1. **数据流改造**：BL 模型在 `OnSecuritiesChanged()` 中只加载价格历史。要注入因子暴露，需要让 BL 模型能访问 `AShareBarraCNE5V2FactorData`，这需要改造算法层向 Portfolio 层传递因子数据。

2. **因子暴露矩阵的时变性**：每只股票的因子暴露不是固定的（momentum 每天在变），但 BL 的 `ReturnsSymbolData` 是按日更新的。需要设计因子暴露的更新频率。

3. **特质收益估计**：需要做截面回归（Fama-MacBeth）来分离因子收益和特质收益，这在 LEAN 框架中没有现成工具。

4. **与 LEAN 原生 BL 解耦**：需要自定义 `IPortfolioConstructionModel`，不能再直接用 `BlackLittermanOptimizationPortfolioConstructionModel`，因为其 `GetEquilibriumReturns()` 是 `virtual` 但 `FormReturnsMatrix()` 不是。

## 一句话总结

> Alpha 层用因子语言选股（"我看好高 momentum 低 resvol 的股票"），Portfolio 层用价格协方差配权（"我不知道 momentum 和 resvol 是什么"）。两者对风险的理解不一致，导致 Alpha 层精心控制的因子暴露在 Portfolio 层被无意中扭曲。用因子模型协方差替代样本协方差，让两层用同一套风险语言，是根本性解决方案。
