# Local Source — 人工输入重要信息

将你看到的重要财经/量化信息放入此目录，系统会自动发现并处理。

## 目录结构

```
local-src/
├── README.md              # 本说明文件
├── 2026-06-19-fed-rate-decision.md      # 按日期+主题命名
├── urls/                  # 纯 URL 书签文件
│   └── 2026-06-19-important-urls.txt    # 每行一个 URL
└── clips/                 # 剪报/截图文本
    └── 2026-06-19-reuters-china-policy.txt
```

## 文件命名规范

- 格式：`YYYY-MM-DD-主题关键词.扩展名`
- 示例：`2026-06-19-pboc-mlf-rate.md`

## 支持的文件类型

| 类型 | 处理方式 |
|------|----------|
| `.md` / `.txt` | 直接读取内容，送 LLM 评分 |
| `.url` / `urls/*.txt` | 提取 URL，爬取内容后评分 |
| `.pdf` | 提取文本后评分 |

## 处理流程

1. 系统每 5 分钟扫描此目录
2. 发现新文件或修改的文件
3. 内容送 LLM 进行重磅性评分（0-10）
4. 评分 ≥ 5 的内容自动进入爬取筛选流程
5. 所有指标写入 InfluxDB，可在 Grafana 中查看
